# Run The Website

## Option A: Start without VSCode
1. Double-click `start_webapp.bat`.
2. The browser opens automatically. It will use the first free port in 8501-8510.
3. Keep the terminal window open while using the site.

## Option B: Start inside VSCode
1. Open Terminal -> Run Task.
2. Choose `Run Web App (Streamlit)`.
3. Open http://localhost:8501.

## Stop the website
- In the running terminal window, press `Ctrl + C`.

## Why this is not always online
A local website is available only while your PC and app are running.
If you want a fixed public URL (24/7), deploy to cloud (for example Render or a VPS).
